**文件**: `c:\AgentGithub\AgentLaboratory\logger_manager.py`

**核心类**: `AgentLabLogger`

**功能清单**:
- ✅ 完整执行日志 (`full_execution.log`)
- ✅ LLM交互日志 (`llm_interactions.log`)

- ✅ UTF-8编码支持中文

**主要方法**:
```python
logger.info(message)                    # 记录信息
logger.warning(message)                 # 记录警告
logger.error(message, exception)        # 记录错误
logger.log_phase_start(phase_name)      # 记录阶段开始
logger.log_phase_end(phase, duration)   # 记录阶段结束
logger.log_subtask_start(subtask)       # 记录子任务开始
logger.log_subtask_end(subtask, dur)    # 记录子任务结束
logger.log_llm_interaction(...)         # 记录LLM交互
logger.log_file_saved(path, type)       # 记录文件保存
logger.log_agent_response(agent, resp)  # 记录Agent响应
logger.log_dialogue(speaker, content)   # 记录对话
logger.log_code_execution(code, result) # 记录代码执行
logger.log_reward_score(phase, score)   # 记录奖励分数
```

## 📊 日志文件说明

### 日志目录结构
```
experiments/
└── 20251223_143000_你的研究主题/
    └── logs/
        ├── full_execution.log      # 完整执行日志 (所有信息)
        ├── llm_interactions.log    # LLM交互记录 (模型调用)
        ├── errors.log              # 错误日志 (警告+错误)
        ├── phases.log              # 阶段统计 (进度追踪)
        └── state_*.pkl             # 状态保存文件
```

### 日志级别
- **DEBUG**: 详细调试信息（仅文件）
- **INFO**: 一般信息（文件+控制台）
- **WARNING**: 警告信息
- **ERROR**: 错误信息
