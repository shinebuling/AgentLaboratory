# Agent Laboratory 使用示例

## 交互示例

当系统运行到需要你确认的阶段时，会显示类似以下内容：

### 例1：文献综述阶段
```
Presented is the result of the phase [literature review]: 

我已经找到了5篇相关论文：
1. Chain-of-Thought Prompting Elicits Reasoning in Large Language Models
2. Tree of Thoughts: Deliberate Problem Solving with Large Language Models
...

Are you happy with the presented content? Respond Y or N: 
```

**你的回应：**
- 输入 `Y` 并回车 → 继续下一阶段
- 输入 `N` 并回车 → 系统会询问改进建议

### 例2：计划制定阶段
```
Presented is the result of the phase [plan formulation]: 

实验计划：
1. 实现一个增强版的思维链提示方法
2. 在MATH-500数据集上评估
3. 比较与基线方法的性能
...

Are you happy with the presented content? Respond Y or N: 
```

**你的回应：**
```
> N
Please provide notes for the agent so that they can try again: 
> 请增加更多关于数学推理步骤分解的细节，并考虑使用自洽性投票机制
```

### 例3：实验结果阶段
```
Presented is the result of the phase [results interpretation]: 

实验结果分析：
- 新方法在MATH-500上达到75.3%准确率
- 相比基线(70.2%)提升了5.1%
- 在几何和代数题目上改进最明显
...

Are you happy with the presented content? Respond Y or N: 
```

## 常用命令

### 查看当前进度
系统会显示当前阶段，例如：
```
**************************************************
Beginning phase: literature review
**************************************************
&&&&&&&&&&&&&&&&&&&&&&&&&&&&&&
Beginning subtask: literature review
&&&&&&&&&&&&&&&&&&&&&&&&&&&&&&
```

### 中断和恢复
- **中断**: 按 `Ctrl+C`
- **恢复**: 系统会自动保存状态到 `state_saves/`，可以设置 `load-existing: True` 恢复

### 查看生成的文件
```powershell
# 查看研究目录
ls MATH_research_dir/research_dir_0_lab_1/

# 查看实验代码
cat MATH_research_dir/research_dir_0_lab_1/src/run_experiments.py

# 查看报告
cat MATH_research_dir/research_dir_0_lab_1/report.txt

# 打开生成的PDF
start MATH_research_dir/research_dir_0_lab_1/tex/temp.pdf
```

## 自定义研究主题

### 方法1：修改YAML配置
编辑 `experiment_configs/MATH_agentlab.yaml`:
```yaml
research-topic: "设计一个新的多模态推理框架用于视觉问答任务"
```

### 方法2：启动时输入
如果YAML中设置了 `copilot-mode: True`，启动时会询问：
```
Please name an experiment idea for AgentLaboratory to perform: 
> 探索基于强化学习的提示优化方法
```

## 高级功能

### 并行运行多个实验
编辑YAML：
```yaml
parallel-labs: True
num-parallel-labs: 4
num-papers-to-write: 4
```

### 使用AgentRxiv（论文共享）
```yaml
agentRxiv: True
construct-agentRxiv: True
agentrxiv-papers: 5
```

### 自定义模型
```yaml
llm-backend: "gpt-4o"  # 或 "o3-mini", "o1", "deepseek-chat"
api-key: "your-openai-api-key"
```

## Web应用使用

### 1. 上传论文
1. 访问 http://127.0.0.1:5000/upload
2. 选择PDF文件
3. 点击"上传论文"

### 2. 搜索论文
1. 访问 http://127.0.0.1:5000/search
2. 输入关键词，例如："transformer architecture"
3. 系统会显示语义相似度最高的论文

### 3. 查看论文
点击论文标题即可在线预览PDF

## 完整工作流程示例

```powershell
# 1. 设置API密钥
$env:DEEPSEEK_API_KEY = "your-api-key"

# 2. 启动系统
.\start_agent_lab.ps1

# 3. 系统开始工作
# [等待] 文献综述阶段...
# [交互] 确认文献是否满意 → 输入 Y

# [等待] 计划制定阶段...
# [交互] 确认实验计划 → 输入 Y

# [等待] 数据准备阶段...
# [交互] 确认数据代码 → 输入 Y

# [等待] 运行实验阶段...
# (自动运行，可能需要几分钟到几小时)

# [等待] 结果解释阶段...
# [交互] 确认结果分析 → 输入 Y

# [等待] 报告撰写阶段...
# [交互] 确认研究报告 → 输入 Y

# [等待] 报告审查阶段...
# [交互] 是否接受或要求改进 → 输入 Y/N

# 4. 查看结果
ls MATH_research_dir/research_dir_0_lab_1/
cat MATH_research_dir/research_dir_0_lab_1/report.txt
start MATH_research_dir/research_dir_0_lab_1/tex/temp.pdf
```

## 时间估算

| 阶段 | 预计时间 | 说明 |
|------|----------|------|
| 文献综述 | 5-10分钟 | 取决于论文数量 |
| 计划制定 | 2-5分钟 | AI生成计划 |
| 数据准备 | 3-8分钟 | 编写数据加载代码 |
| 运行实验 | 10分钟-数小时 | 取决于实验复杂度 |
| 结果解释 | 3-5分钟 | 分析结果 |
| 报告撰写 | 10-20分钟 | 生成完整报告 |
| 报告审查 | 5-10分钟 | 三位审稿人评审 |

**总计**: 约40分钟 - 数小时（取决于实验复杂度）
