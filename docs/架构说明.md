# Agent Laboratory 架构说明

## 🏗️ 整体架构概览

Agent Laboratory 是一个**单体系统，但包含两个可选功能模块**：

1. **AgentLab（核心系统）** - 自动化研究工作流
2. **AgentRxiv（可选模块）** - 研究成果共享和检索平台

它们**不是独立系统**，而是**集成在同一个代码库中**，AgentRxiv 作为 AgentLab 的一个增强功能存在。

## 🔗 AgentLab 和 AgentRxiv 的关系

### 关系模式

```
┌─────────────────────┐
│   AgentLab          │
│   (主系统)          │
│                     │
│   研究流程          │
│   ↓                 │
│   生成论文 PDF       │
│   ↓                 │
│   [可选] 上传到      │ ────→  ┌──────────────────┐
│   AgentRxiv         │        │   AgentRxiv      │
│   ↓                 │        │   (论文库)       │
│   [可选] 从         │ ←────  │                  │
│   AgentRxiv检索     │        │   • 存储论文     │
│   相关论文          │        │   • 语义搜索     │
│                     │        │   • 提供引用     │
└─────────────────────┘        └──────────────────┘
```

### 集成方式

#### 1. **启用 AgentRxiv** (配置文件设置)

```yaml
# experiment_configs/MATH_agentrxiv.yaml
agentRxiv: True
construct-agentRxiv: True
agentrxiv-papers: 5  # 每次文献综述从AgentRxiv检索的论文数
```

#### 2. **工作流程**

```python
# 主程序入口 (ai_lab_repo.py)

if agentRxiv:
    # 1. 初始化 AgentRxiv 服务器
    GLOBAL_AGENTRXIV = AgentRxiv(lab_index)
    # 启动 Flask 服务器在端口 5000 + lab_index
    
# 2. 创建研究工作流
lab = LaboratoryWorkflow(
    research_topic=research_topic,
    agentRxiv=True,  # 告诉系统启用AgentRxiv功能
    agentrxiv_papers=5
)

# 3. 执行研究
lab.perform_research()
    # 在文献综述阶段:
    #   - 搜索传统 arXiv
    #   - 同时搜索 GLOBAL_AGENTRXIV
    #   - 合并结果
    
    # 在报告撰写阶段:
    #   - 生成 PDF
    #   - 自动上传到 AgentRxiv (uploads/)
```

#### 3. **数据流**

```
Research Topic (研究主题)
    ↓
[文献综述阶段]
    ├→ arXiv Search (传统论文搜索)
    └→ AgentRxiv Search (本地论文搜索) ← 之前生成的论文
    ↓
合并文献 → 计划制定 → 实验执行 → 报告撰写
                                        ↓
                                生成 PDF 论文
                                        ↓
                            上传到 AgentRxiv (uploads/)
                                        ↓
                            可供未来研究引用
```

## 📁 代码结构映射

### 核心文件职责

| 文件 | 职责 | 系统归属 |
|-----|-----|---------|
| `ai_lab_repo.py` | 主入口，包含 `LaboratoryWorkflow` 和 `AgentRxiv` 类 | 两者都有 |
| `agents.py` | 定义所有智能体角色 | AgentLab |
| `mlesolver.py` | 机器学习实验求解器 | AgentLab |
| `papersolver.py` | 论文撰写求解器 | AgentLab |
| `app.py` | Flask Web 应用 | AgentRxiv |
| `inference.py` | LLM 推理接口 | 共享 |
| `tools.py` | 工具函数（搜索、执行等） | 共享 |
| `utils.py` | 通用工具 | 共享 |

### 数据流向

```
用户输入 (research_topic)
    ↓
ai_lab_repo.py (主控制器)
    ├→ agents.py (智能体推理)
    │   └→ inference.py (LLM调用)
    ├→ tools.py (搜索、执行工具)
    │   ├→ ArxivSearch
    │   ├→ HFDataSearch
    │   └→ GLOBAL_AGENTRXIV (如果启用)
    ├→ mlesolver.py (实验优化)
    ├→ papersolver.py (论文生成)
    └→ app.py (AgentRxiv服务器)
        └→ uploads/ (论文存储)
```

## 🚀 使用场景

### 场景 1: 仅使用 AgentLab (独立研究)

```yaml
agentRxiv: False
```

**流程**:
1. 指定研究主题
2. 从 arXiv 搜索论文
3. 执行研究流程
4. 生成论文报告
5. 保存到本地目录

**适用于**: 单次研究、不需要累积知识的场景

---

### 场景 2: 使用 AgentLab + AgentRxiv (累积研究)

```yaml
agentRxiv: True
construct-agentRxiv: True
agentrxiv-papers: 5
parallel-labs: True
num-parallel-labs: 8
```

**流程**:
1. 启动 AgentRxiv 服务器
2. 多个并行实验室同时运行
3. 每个实验室:
   - 从 arXiv + AgentRxiv 检索论文
   - 执行研究
   - 上传结果到 AgentRxiv
4. 后续实验室可以引用之前的成果

**适用于**: 
- 多次迭代研究
- 团队协作
- 累积知识构建
- 大规模并行实验

## 🎯 关键设计理念

### 1. **单一代码库，模块化功能**
- AgentRxiv 不是独立项目，而是 AgentLab 的增强模块
- 通过配置文件控制是否启用

### 2. **可选依赖**
- 不使用 AgentRxiv 时，不需要运行 Flask 服务器
- 系统自动检测并适应配置

### 3. **全局单例模式**
```python
GLOBAL_AGENTRXIV = None  # 全局实例

if agentRxiv:
    GLOBAL_AGENTRXIV = AgentRxiv(lab_index)
    # 所有 LaboratoryWorkflow 实例共享同一个 AgentRxiv
```

### 4. **线程安全**
```python
self.server_thread = threading.Thread(target=lambda: self.run_server(port))
self.server_thread.daemon = True  # 守护线程，主程序退出时自动关闭
```

## 📊 性能考虑

### 并行执行

```python
# 多个 Lab 并行运行，共享一个 AgentRxiv
with ThreadPoolExecutor(max_workers=num_parallel_labs) as executor:
    futures = [executor.submit(run_lab, lab_idx) 
               for lab_idx in range(num_parallel_labs)]
```

**优势**:
- 每个 Lab 独立运行研究流程
- 共享同一个论文库
- 动态端口分配 (5000 + lab_index)

## 🎓 总结

### AgentLab 和 AgentRxiv 的关系

| 维度 | AgentLab | AgentRxiv |
|-----|----------|-----------|
| **定位** | 核心研究系统 | 可选增强模块 |
| **独立性** | 可独立运行 | 依赖 AgentLab |
| **功能** | 执行研究流程 | 论文存储与检索 |
| **代码位置** | `LaboratoryWorkflow` 类 | `AgentRxiv` 类 + `app.py` |
| **启用方式** | 始终运行 | 配置文件控制 |
| **数据流** | 生产者（生成论文） | 消费者+生产者（存储+检索） |

### 核心理解

✅ **不是独立系统** - AgentRxiv 是 AgentLab 的一个功能模块  
✅ **可选启用** - 通过 `agentRxiv: True/False` 控制  
✅ **单向依赖** - AgentRxiv 需要 AgentLab，反之不成立  
✅ **共享资源** - 在并行模式下，多个 Lab 共享一个 AgentRxiv 实例  
✅ **增强功能** - 启用后可实现累积式研究和知识复用
